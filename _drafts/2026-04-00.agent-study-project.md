# LLM Agent 로 특정 분야 공부하기

GPT 스타일의 기존 AI 사용은 주로 수동적인 질답으로 이루어진다. 여러 발전을 통해 먼저 (오히려 귀찮을만큼) 질문을 하기도 하지만 1회성의 성격이 강하다. 예전엔 진짜로 일회성이 질답에 가까웠다면 요즘은 세션 단위라서 조금 낫긴 하지만 세션을 넘어서 장기간 진행하기에는 다소 아쉽다[^1].

코끼리의 치아는 몇개냐는 단순한 질답도 충분히 우리의 호기심을 채워주긴 하지만 좀 더 깊고 장시간 LLM Agent 의 도움을 받는 시스템을 만들어 보았다.

[agent-study](https://github.com/Hybrid3D/agent-study)는 claude code 나 codex 등을 이용하여 내가 특정 분야를 장시간 깊게 공부하기 위한 시스템이다. 내가 무엇을 알고자 하는지를 목표점으로, 현재 무엇을 알고 무엇을 모르는지, 그리고 무엇을 알아가고 있는 지를 기록하면서 배우는 시스템이다.

지금은 쓰임세가 많이 줄었지만 내가 [stackoverflow](https://stackoverflow.com/) 같은 곳에 질문을 옮긴다고 해보자. 여기서 단순히 내가 궁금한 것을 적는 것 만으로는 정말로 내가 원하는 것을 얻기 힘들다.

- 내가 무엇을 알고 있는지
- 내가 무엇을 알고 싶은지
- 내가 무엇을 모르는지 (보통은 무엇을 모르는지도 모르기 때문에 이것을 명시적으로 해둘 수 있으면 좋다)
- 알기 위해서 무엇을 해보았는지

이와 같은 것을 남기면 내가 원하는 정말 내가 알고 싶은 것을 얻을 확률이 높아진다.

사람 대신 AI에게 배우기 위해 나의 지식 상태를 아래와 같이 네 가지 **지식 상태(knowledge state)**로 구분하였다. 이것은 어떤 지식에 대한 나의 상태를 의미한다.


[README.ko.md](https://github.com/Hybrid3D/agent-study/blob/template/README.ko.md)에 위와 같이 정리를 해두었다.

- **목표 & 배경** -- 최종 목표, 사전 지식, 선호하는 학습 방식
- **플랜 & 현재 Phase** -- 단계별 플랜과 지금 어디에 있는지
- **확실히 이해한 개념** -- 다음 설명에서 건너뛰어도 되는 것들
- **헷갈리는 개념** -- 부분적으로만 이해한, 다시 짚어줘야 하는 것들
- **바로잡은 오개념** -- 잘못 알고 있던 모델 → 올바른 이해
- **보류된 질문** -- 흐름상 미뤄둔, 적절한 시점에 다시 꺼낼 질문
- **레퍼런스** -- 모아둔 논문·아티클·링크·PDF



[^1]: Compaction, memory 등의 기등이 있긴 하지만 이것만으로는 다소 아쉽다.
